1. Hướng dẫn tải source code vào engine để chạy game.
- Bấm vào button Code (màu xanh lá cây), chọn Download ZIP, giải nén.
- Vào trang chủ của Unity: " https://unity.com/ ", tải Unity HUB
- Cài đặt Unity HUB xong, vào phần Installs -> Install Editor -> Tải phiên bản Unity 2022.3 LTS
- Sang phần Projects, chọn Add -> tìm đến đường dẫn đã tải source code -> click để mở
- Tải Visual Studio 2022, cài đặt mục Game Dev C# để có thể chỉnh sửa code, tương tác với Unity Editor.

2. Hướng dẫn trải nghiệm game trên web.
- Truy cập vào trang web: " https://itch.io/ ", đăng ký/đăng nhập tài khoản.
- Truy cập đường link " https://rinoniz.itch.io/pikachu ", chọn Run Game để chơi.
